Problem 1: Noisy Linear Multi-Dimensional Data Generation

Part a) Build the Function

The function noisyLinearMultiDim(N, a, b; σ²) (saved in src/Problem1.jl) returns $N$ samples of an $m$-dimensional noisy linear data set, where $m$ is the length of the coefficient vector $\mathbf{b}$:

  1. The input matrix $\mathbf{X}$ ($N \times m$) is filled with rand(N, m), so every entry is drawn independently from $\mathcal{U}(0,1)$.

  2. The clean linear part is computed for all rows at once as $a + \mathbf{X}\mathbf{b}$.

  3. Gaussian noise is added. Because σ² is a variance, a standard-normal draw is scaled by the standard deviation $\sqrt{\sigma^2}$:

\[ \hat{Y}_n = a + b_1X_{n,1} + \dots + b_mX_{n,m} + \sqrt{\sigma^2}\,z_n, \qquad z_n \sim \mathcal{N}(0,1). \]

A quick check on a small example confirms the sizes of the outputs and that, with zero noise, the targets equal the clean linear function exactly.

Random.seed!(1)
𝐗, Ŷ = noisyLinearMultiDim(5, 5.0, [1.0, 2.0]; σ²=0.0)
println("size(𝐗) = ", size(𝐗), ",  length(Ŷ) = ", length(Ŷ))
println("max |Ŷ - (a + 𝐗b)| with σ² = 0 : ",
        maximum(abs.(Ŷ .- (5.0 .+ 𝐗*[1.0, 2.0]))))

size(𝐗) = (5, 2),  length(Ŷ) = 5
max |Ŷ - (a + 𝐗b)| with σ² = 0 : 0.0

Problem 3: Bivariate Regression

Part a) Build the Function

The function bivariate(𝐗, 𝐘) (saved in src/Problem3.jl) follows the subject-space derivation from the lecture and uses no fitting package:

  1. Centre both variables: $x_i = X_i - \bar{X}$ and $y_i = Y_i - \bar{Y}$.

  2. The best centred prediction $\hat{\mathbf{y}} = b\mathbf{x}$ makes the error orthogonal to $\mathbf{x}$, i.e. $\mathbf{x}\cdot(\mathbf{y} - b\mathbf{x}) = 0$, giving $b = \frac{\mathbf{x}\cdot\mathbf{y}}{\|\mathbf{x}\|^2}.$

  3. Return to the uncentred data: $a = \bar{Y} - b\bar{X}$.

The function is checked against the ten-point example from the lecture slides, for which the hand calculation gives $b = 56/28 = 2$ and $a = 12 - 2\cdot 4 = 4$:

𝐗ₛ = [1.0, 1, 3, 3, 4, 4, 5, 6, 6, 7]
𝐘ₛ = [4.0, 7, 9, 12, 11, 12, 17, 13, 18, 17]
a, b = bivariate(𝐗ₛ, 𝐘ₛ)
println("a = ", a, ",  b = ", b)

a = 4.0,  b = 2.0

The goodness-of-fit measure reported below is the correlation coefficient from the lecture, $R = \cos\angle[\hat{\mathbf{y}}, \mathbf{y}] = \|\hat{\mathbf{y}}\| / \|\mathbf{y}\|$.

Problem 4: Multiple Regression

Part a) Build the Function

The function multivariate(𝐗₁, 𝐗₂, 𝐘) (saved in src/Problem4.jl) again works with centred variables $\mathbf{x}_1, \mathbf{x}_2, \mathbf{y}$. Requiring the error $\mathbf{e} = \mathbf{y} - b_1\mathbf{x}_1 - b_2\mathbf{x}_2$ to be orthogonal to both $\mathbf{x}_1$ and $\mathbf{x}_2$ gives the normal equations

\[ \begin{aligned} b_1(\mathbf{x}_1\cdot\mathbf{x}_1) + b_2(\mathbf{x}_1\cdot\mathbf{x}_2) &= \mathbf{x}_1\cdot\mathbf{y}\\ b_1(\mathbf{x}_2\cdot\mathbf{x}_1) + b_2(\mathbf{x}_2\cdot\mathbf{x}_2) &= \mathbf{x}_2\cdot\mathbf{y} \end{aligned} \]

which the function solves in closed form,

\[ b_1 = \frac{(\mathbf{x}_1\cdot\mathbf{y})(\mathbf{x}_2\cdot\mathbf{x}_2) - (\mathbf{x}_2\cdot\mathbf{y})(\mathbf{x}_1\cdot\mathbf{x}_2)}{(\mathbf{x}_1\cdot\mathbf{x}_1)(\mathbf{x}_2\cdot\mathbf{x}_2) - (\mathbf{x}_1\cdot\mathbf{x}_2)^2},\qquad b_2 = \frac{(\mathbf{x}_2\cdot\mathbf{y})(\mathbf{x}_1\cdot\mathbf{x}_1) - (\mathbf{x}_1\cdot\mathbf{y})(\mathbf{x}_1\cdot\mathbf{x}_2)}{(\mathbf{x}_1\cdot\mathbf{x}_1)(\mathbf{x}_2\cdot\mathbf{x}_2) - (\mathbf{x}_1\cdot\mathbf{x}_2)^2}, \]

and finally $a = \bar{Y} - b_1\bar{X}_1 - b_2\bar{X}_2$. If the denominator is zero the two predictors are collinear and the function raises an error.

Check on the eleven-point example from the lecture slides. The result is compared with the least-squares solution of the full system $[\mathbf{1}\;\mathbf{X}_1\;\mathbf{X}_2]\,\boldsymbol{\beta} = \mathbf{Y}$ computed with Julia's backslash operator (used here only as an independent check, not inside the function):

Problem 5: Polynomial Curve Fitting

Part a) Build the Function

The function polyfitLS(𝐗, 𝐘, M) (saved in src/Problem5.jl) implements Algorithm 1:

  1. Build the $N \times (M+1)$ design matrix $\boldsymbol{\Phi}$ one column at a time, $\Phi_{n,m+1} = X_n^m$ for $m = 0,\dots,M$ (column 1 is all ones).

  2. Compute the least-squares weights $\mathbf{w}^\star = (\boldsymbol{\Phi}^H\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^H\mathbf{Y} = \boldsymbol{\Phi}^\dagger\mathbf{Y}.$

The pseudoinverse $\boldsymbol{\Phi}^\dagger$ is evaluated with pinv (imported in the template), which is mathematically identical to $(\boldsymbol{\Phi}^H\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^H$ but is computed through the SVD of $\boldsymbol{\Phi}$. This matters for $M=9$: the $10\times10$ Vandermonde matrix is badly conditioned and forming $\boldsymbol{\Phi}^H\boldsymbol{\Phi}$ squares its condition number, which amplifies round-off error. No fitting package is used; Julia's Polynomial type is used only to evaluate the fitted model.

The training data and the error measure used throughout this problem are

\[ E(\mathbf{w}) = \tfrac{1}{2}\sum_{n=1}^{N}\big(Y_n - \hat{Y}(X_n,\mathbf{w})\big)^2, \qquad E_{\text{RMS}} = \sqrt{2E(\mathbf{w}^\star)/N}. \]

Dᶜ = loadData("curvefitting.txt")
𝐗ᵗʳ = Dᶜ[:,1]          # inputs  (first column)
𝐘ᵗʳ = Dᶜ[:,2]          # targets (second column)

# root-mean-square error of the polynomial with weights 𝐰 on (𝐗, 𝐘)
function Eʳᵐˢ(𝐰, 𝐗, 𝐘)
    E = 0.5*sum((𝐘 .- Polynomial(𝐰).(𝐗)).^2)
    return sqrt(2E/length(𝐗))
end

println("N = ", length(𝐗ᵗʳ), " training points loaded from curvefitting.txt")

Problem 6: Polynomial Regression with Regularization

Part a) Build the Function

The function polyfitRegLS(𝐗, 𝐘, M, λ) (saved in src/Problem6.jl) implements Algorithm 2. It minimizes the regularized error

\[ \tilde{E}(\mathbf{w}) = \tfrac{1}{2}\sum_{n=1}^{N}\big(Y_n - \hat{Y}(X_n,\mathbf{w})\big)^2 + \tfrac{\lambda}{2}\|\mathbf{w}\|^2, \]

whose minimizer is

\[ \mathbf{w}^\star = (\lambda\mathbf{I} + \boldsymbol{\Phi}^H\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^H\mathbf{Y}. \]

The design matrix $\boldsymbol{\Phi}$ is built exactly as in polyfitLS. Instead of forming the inverse explicitly, the function solves the linear system $(\lambda\mathbf{I} + \boldsymbol{\Phi}^H\boldsymbol{\Phi})\mathbf{w} = \boldsymbol{\Phi}^H\mathbf{Y}$ with the backslash operator, which is cheaper and more accurate. Adding $\lambda\mathbf{I}$ also lifts the smallest eigenvalues of $\boldsymbol{\Phi}^H\boldsymbol{\Phi}$, so the system is far better conditioned than the unregularized one. Setting $\lambda = 0$ recovers the ordinary least-squares solution, which is used below as a consistency check:

Dᶜ = loadData("curvefitting.txt")

𝐘ᵗʳ = Dᶜ[:,2]

𝐰ₗₛ = polyfitLS(𝐗ᵗʳ, 𝐘ᵗʳ, 3)
println("max |w(λ=0) - w_LS| for M = 3 : ", maximum(abs.(𝐰₀ .- 𝐰ₗₛ)))

    export noisyLinearMultiDim

    # Draws N samples of an m-dimensional noisy linear data set
    #   𝐗[n,j] ~ U(0,1)
    #   Ŷ[n]   = a + b₁𝐗[n,1] + ... + bₘ𝐗[n,m] + 𝒩(0,σ²)
    # σ² is the noise variance, so the noise is scaled by √σ²
    function noisyLinearMultiDim(N::Integer, a::Float64 , b::Vector{Float64}; σ²=0.001)

        m = length(b)

        # inputs drawn uniformly on [0,1), one row per sample
        𝐗 = rand(N, m)

        # clean linear part: a + 𝐗b, then add Gaussian noise
        Ŷ = a .+ 𝐗*b .+ sqrt(σ²) .* randn(N)

        return 𝐗::Matrix{Float64},Ŷ::Vector{Float64}
    end
    
end

module Problem3

    using Statistics
    export bivariate

    # Bivariate regression Ŷ = a + b𝐗 (subject-space formulation)
    #   centre the data:  x = 𝐗 - X̄,  y = 𝐘 - Ȳ
    #   project y on x:   b = (x⋅y)/‖x‖²
    #   recover offset:   a = Ȳ - bX̄
    function bivariate(𝐗::Vector{Float64}, 𝐘::Vector{Float64})

        if length(𝐗) != length(𝐘)
            error("𝐗 and 𝐘 must have the same length")
        end

        X̄ = mean(𝐗)
        Ȳ = mean(𝐘)

        # centred variables
        𝐱 = 𝐗 .- X̄
        𝐲 = 𝐘 .- Ȳ

        b = sum(𝐱 .* 𝐲) / sum(𝐱 .* 𝐱)
        a = Ȳ - b*X̄

        return a::Float64, b::Float64
    end 

end
Problem4.jl
module Problem4
    
    using Statistics
    export multivariate

    # Multiple regression Ŷ = a + b₁𝐗₁ + b₂𝐗₂
    # Solves the normal equations of the centred problem
    #   b₁(x₁⋅x₁) + b₂(x₁⋅x₂) = x₁⋅y
    #   b₁(x₂⋅x₁) + b₂(x₂⋅x₂) = x₂⋅y
    # in closed form, then a = Ȳ - b₁X̄₁ - b₂X̄₂
    function multivariate(𝐗₁::Vector{Float64}, 𝐗₂::Vector{Float64}, 𝐘::Vector{Float64})
        
        if !(length(𝐗₁) == length(𝐗₂) == length(𝐘))
            error("𝐗₁, 𝐗₂ and 𝐘 must have the same length")
        end

        X̄₁ = mean(𝐗₁)
        X̄₂ = mean(𝐗₂)
        Ȳ  = mean(𝐘)

        # centred variables
        𝐱₁ = 𝐗₁ .- X̄₁
        𝐱₂ = 𝐗₂ .- X̄₂
        𝐲  = 𝐘  .- Ȳ

        # dot products appearing in the normal equations
        s₁₁ = sum(𝐱₁ .* 𝐱₁)
        s₂₂ = sum(𝐱₂ .* 𝐱₂)
        s₁₂ = sum(𝐱₁ .* 𝐱₂)
        s₁y = sum(𝐱₁ .* 𝐲)
        s₂y = sum(𝐱₂ .* 𝐲)

        D = s₁₁*s₂₂ - s₁₂^2
        if D == 0
            error("𝐗₁ and 𝐗₂ are collinear; the normal equations are singular")
        end

        b₁ = (s₁y*s₂₂ - s₂y*s₁₂) / D
        b₂ = (s₂y*s₁₁ - s₁y*s₁₂) / D
        a  = Ȳ - b₁*X̄₁ - b₂*X̄₂

        return a::Float64, b₁::Float64, b₂::Float64
    end 

end

module Problem5    
    
    using LinearAlgebra:pinv
    export polyfitLS

    # Least squares polynomial regression (Algorithm 1)
    #   𝚽[n,m+1] = 𝐗[n]^m,  m = 0,…,M
    #   𝐰 = (𝚽ᴴ𝚽)⁻¹𝚽ᴴ𝐘 = 𝚽†𝐘
    function polyfitLS(𝐗::Vector{Float64}, 𝐘::Vector{Float64}, M::Integer)
        N = length(𝐗)
        if N<M; error("M must be less than the length of 𝐗"); end
        𝚽 = zeros(N,M+1)

        # build the design (Vandermonde) matrix column by column
        for m in 0:M
            𝚽[:,m+1] = 𝐗.^m
        end

        # 𝚽† = (𝚽ᴴ𝚽)⁻¹𝚽ᴴ; pinv computes it through the SVD, which is
        # numerically safer than inverting 𝚽ᴴ𝚽 when M is large
        𝐰 = pinv(𝚽)*𝐘

        return 𝐰::Vector{Float64}
    end

end

module Problem6    
    
    using LinearAlgebra
    export polyfitRegLS

    # Regularized least squares polynomial regression (Algorithm 2)
    #   𝚽[n,m+1] = 𝐗[n]^m,  m = 0,…,M
    #   𝐰 = (λ𝐈 + 𝚽ᴴ𝚽)⁻¹𝚽ᴴ𝐘
    function polyfitRegLS(𝐗::Vector{Float64}, 𝐘::Vector{Float64}, M::Integer, λ::Float64)
        N = length(𝐗)
        if N<M; error("M must be less than the length of 𝐗"); end
        𝚽 = zeros(N,M+1)

        # build the design (Vandermonde) matrix column by column
        for m in 0:M
            𝚽[:,m+1] = 𝐗.^m
        end

        # solve (λ𝐈 + 𝚽ᴴ𝚽)𝐰 = 𝚽ᴴ𝐘 directly instead of forming the inverse
        𝐀 = λ*I + 𝚽'*𝚽
        𝐰 = 𝐀 \ (𝚽'*𝐘)

        return 𝐰::Vector{Float64}
    end

end
