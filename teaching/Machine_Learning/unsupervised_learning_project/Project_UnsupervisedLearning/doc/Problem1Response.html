Part a)

The histogram function was implemented by first determining the minimum and maximum values of the observations. The bin locations are equally spaced between these values. Each observation is then assigned to its nearest bin.

# bold X /= ordinary x
    function histo(𝐱::Vector, B::Integer)

        # \bfx (bold x)
        # x \_m \_i \_n
        xₘᵢₙ  = minimum(𝐱)
        xₘₐₓ = maximum(𝐱)

        bₙ = range(xₘᵢₙ,xₘₐₓ,length=B)

        hᵢ = zeros(B)

        for m in 1:length(𝐱)
            eₙ = zeros(B)
            for n in 1:B 
                eₙ[n]=abs(bₙ[n]- 𝐱[m])
            end
            i = argmin(eₙ)
            hᵢ[i] += 1
        end 

        return bₙ::StepRangeLen,hᵢ::Vector{Float64}
    end

Part b)

The same (N=1000) samples drawn from a normal distribution with (\mu=0) and (\sigma=1) are used for all three histograms.

using Plots

𝐱 = randn(1000)

b₅, h₅ = histo(𝐱, 5)
b₅₀, h₅₀ = histo(𝐱, 50)
b₅₀₀, h₅₀₀ = histo(𝐱, 500)

p₁ = bar(b₅, h₅,
    xlabel="value", ylabel="frequency",
    title="B = 5", legend=false)

p₂ = bar(b₅₀, h₅₀,
    xlabel="value", ylabel="frequency",
    title="B = 50", legend=false)

p₃ = bar(b₅₀₀, h₅₀₀,
    xlabel="value", ylabel="frequency",
    title="B = 500", legend=false)

plot(p₁, p₂, p₃, layout=(3,1), size=(800,900))

Part c)

The choice of bin size (B) controls the resolution of the histogram. With (B=5), the histogram is coarse and much of the structure of the data is hidden. With (B=50), the normal distribution becomes clearly visible while the histogram remains relatively smooth. With (B=500), many bins contain very few or no observations, making the histogram more irregular and sensitive to individual samples. Thus, too few bins can oversimplify the distribution, while too many bins can emphasize sampling noise.

comment = """
Effect of the number of bins (B):

B = 5: Coarse representation; details are hidden.
B = 50: Good balance; the normal distribution is clearly visible.
B = 500: Too many bins; the histogram becomes sparse and noisy.

Too few bins oversimplify the distribution,
while too many bins emphasize sampling noise.
"""

p₄ = plot(
    [0], [0],
    annotations=(0, 0, text(comment, 10, :left)),
    xlims=(-1, 1),
    ylims=(-1, 1),
    axis=false,
    grid=false,
    legend=false
)

plot(
    p₁, p₂, p₃, p₄,
    layout=@layout([a; b; c; d{0.25h}]),
