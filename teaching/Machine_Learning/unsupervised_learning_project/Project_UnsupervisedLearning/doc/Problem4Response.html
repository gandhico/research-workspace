Problem 4: Batch K-means

The following helper functions generate the required two-Gaussian data, select unique data points as initial centers, calculate the label-invariant two-center error, and evaluate the K-means objective.

Part a)

myKmeansBatch alternates between assigning every point to its closest centroid and replacing each centroid with the mean of its assigned points. It stops when the largest centroid movement is at most the tolerance or when the iteration limit is reached. If a cluster is empty, its centroid is moved to the distinct data point currently farthest from the other centers. This prevents a division by zero without silently reducing (K).

batch_test_data = [[0.0, 0.0], [0.0, 1.0], [5.0, 5.0], [5.0, 6.0]]
batch_test_initial = [[0.0, 0.0], [5.0, 5.0]]
batch_test_centers, batch_test_r, batch_test_iterations = myKmeansBatch(
    batch_test_data,
    batch_test_initial;
    maxIter=25,
    tol=1e-12,
    verbose=false,

@assert all(sum(batch_test_r, dims=2) .== 1)

The largest conceptual improvement occurs when the model has enough centers to represent the two generating distributions. Beyond that point, additional centers partition variation within the two clouds, so the objective continues to fall even though the underlying data still have only two generating modes.

Part f)

The same (N=500) data set is clustered three times with (K=5), changing only the randomly selected initial centers.

Random.seed!(4106)
fixed_data = two_gaussian_data(500)
initialization_plots = Any[]
initialization_costs = Float64[]

for run in 1:3
    initial = random_unique_centers(fixed_data, 5)
    centers, indicators, iterations = myKmeansBatch(
        fixed_data,
        initial;
        maxIter=100,
        tol=1e-8,
        verbose=false,
    )
    assignments = [findfirst(view(indicators, n, :)) for n in axes(indicators, 1)]
    cost = kmeans_objective(fixed_data, centers)
    push!(initialization_costs, cost)

    panel = scatter(
        [point[1] for point in fixed_data],
        [point[2] for point in fixed_data];
        group=assignments,
        markersize=2.5,
        markerstrokewidth=0,
        xlabel="x1",
        ylabel="x2",
        title="Run $run: J=$(round(cost, digits=1)), $iterations iterations",
        legend=false,
        aspect_ratio=:equal,
    )
    scatter!(
        panel,
        [center[1] for center in centers],
        [center[2] for center in centers];
        marker=:star5,
        markersize=9,
        markercolor=:black,
        label=false,
    )
    push!(initialization_plots, panel)
end
