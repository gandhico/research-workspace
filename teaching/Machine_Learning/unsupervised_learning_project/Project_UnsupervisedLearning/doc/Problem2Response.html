Problem 2

Part a)

The function circGauss generates (N) samples from a circular symmetric multivariate Gaussian distribution. Each dimension is independent and has the same variance (\sigma^2). The standard deviation used to scale the zero-mean Gaussian samples is therefore sqrt(σ²).

The following test verifies that the generated samples have approximately the specified mean and variance.

Random.seed!(2)

μ = [2.0, -3.0]
σ² = 3.0

X = circGauss(100_000, μ, σ²)

@assert length(X) == 100_000
@assert all(length(x) == length(μ) for x in X)

empirical_mean = [
    mean(x[d] for x in X)
    for d in eachindex(μ)
]

empirical_variance = [
    var(x[d] for x in X)
    for d in eachindex(μ)
]

println("Expected mean      = ", μ)
println("Empirical mean     = ", empirical_mean)
println("Expected variance  = ", σ²)
println("Empirical variance = ", empirical_variance)

Expected mean      = [2.0, -3.0]
Empirical mean     = [2.0060379604572036, -3.001640941657761]
Expected variance  = 3.0
Empirical variance = [2.965180979894827, 2.994385704961237]

Part b)

A dataset of (N=500) samples is generated from two two-dimensional circular symmetric Gaussian distributions. The samples are divided equally between the two distributions. The first distribution is centered at ((0,0)), and the second is centered at ((5,5)). Both distributions have variance (\sigma^2=3).

Random.seed!(2)

X₁ = circGauss(250, [0.0, 0.0], 3.0)
X₂ = circGauss(250, [5.0, 5.0], 3.0)

X = vcat(X₁, X₂)

x₁ = [x[1] for x in X]
x₂ = [x[2] for x in X]

scatter(
    x₁,
    x₂,
    markersize=3,
    markerstrokewidth=0,
    xlabel="x₁",
    ylabel="x₂",
    title="Two Circular Symmetric Gaussians (N = 500)",
    legend=false,
    aspect_ratio=:equal
)
