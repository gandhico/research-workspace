# Runners

All runner scripts live in `scripts/` and are PowerShell scripts. They resolve
the project root from their own location, so they can be invoked from anywhere.
Each prefers the project virtual environment (`.venv\Scripts\python.exe`) and
falls back to the `python` on `PATH`.

Run order for a clean rebuild: **setup → experiments → figures → tables → paper**
(or just `build_all.ps1`).

| Script | Purpose | Reads | Writes |
|---|---|---|---|
| `setup_env.ps1` | Create `.venv` and install `requirements.txt`; print versions. | `requirements.txt` | `.venv/` |
| `run_experiments.ps1` | Run `experiments/run_all.py` (all numbered experiments). | `src/` | `results/csv/*.csv`, `results/logs/*.txt` |
| `make_figures.ps1` | Run `figures/make_figures.py`. | `results/csv/*.csv` | `results/figures/*`, `paper/figures/*` (PNG + PDF) |
| `make_tables.ps1` | Run `tables/make_tables.py`. | `results/csv/*.csv`, `src` params | `paper/tables/*.tex` |
| `build_paper.ps1` | `pdflatex → bibtex → pdflatex → pdflatex`. Auto-locates `pdflatex`. | `paper/main.tex`, `paper/figures`, `paper/tables`, `paper/references.bib` | `paper/main.pdf` |
| `build_all.ps1` | Runs experiments → figures → tables → paper in order. | — | all of the above |

## Figure / table entry points

- `figures/make_figures.py` — one function per figure (`fig_step`, `fig_stress`,
  `fig_fi`, `fig_db`, `fig_integration`, `fig_parity`, `fig_decode`); `main()`
  builds all. Never runs a simulation; reads only CSVs.
- `figures/make_candidate_plots.py` — renders the origin-aware candidate
  heatmap, robustness/event-rate scatter, and calibration trend plots from
  `12_origin_aware_calibration_summary.csv`.
- `experiments/make_capability_figure.py` — renders
  `paper/figures/fig_nengo_capability.{png,pdf}` from
  `13_hyperlif_nengo_capability_matrix.csv` and `15_pes_rate_matched.csv`.
- `tables/make_tables.py` — one function per table (`tab_notation`, `tab_params`,
  `tab_model_compare`, `tab_sweep`, `tab_parity`, `tab_decoding`,
  `tab_integration`); `main()` builds all.

## Notes

- The experiment scripts are the **single source of truth** for numerical data.
  Figures and tables are pure functions of the CSV files, so re-running
  `make_figures`/`make_tables` without re-running experiments simply re-renders
  from existing data.
- `08_nef_app_smoke.py` uses the canonical Nengo tuning path for the custom
  neurons, so it is intentionally slower than the single-neuron parity tests.
- `09_core_nengo_capability_sweep.py` uses experiment-local approximate
  build-time rates for HyperLIF decoder solving. The runtime neuron dynamics are
  unchanged, but its decoded RMSE values should be treated as calibration-smoke
  results, not final optimized NEF benchmark values. The static-origin variants
  use `v_reset=-0.6` and `min_voltage=-2.0`; their mixed results are mainly
  evidence that origin-aware gain/rate calibration is still needed.
- `10_full_tuning_setup.py` is a setup generator, not a benchmark. It writes the
  staged matrix described in `FULL_TUNING_SETUP.md`; rows marked
  `local_subclass`, `new_decoder`, `new_learning_rule`, or `app_builder` need a
  separate exploratory implementation before being treated as evidence.
- `11_origin_aware_calibration_sweep.py` is the first candidate benchmark pass
  from that matrix. It intentionally restricts itself to priority-1
  `core_params` rows so the results isolate neuron/readout parameters before any
  decoder or app-builder experiments are introduced.
- `17_capability_seed_sweep.py` defaults to a one-seed interactive smoke because
  one seed takes roughly 11 minutes on this local machine. Use `--preflight` for
  three seeds; this is the current sufficient methods-paper evidence. Reserve
  `--paper` for a five-seed run only if a venue or reviewer asks for broader
  statistical margins. On 2026-07-19, `--preflight` completed 84/84 simulations
  with zero failures and wrote `17_capability_seed_sweep.csv` plus
  `17_capability_seed_sweep_summary.csv`.
- `18_nef_decoder_state_ablation.py` now supports `tab:nef-decoder-ablation`.
  On 2026-07-20, the guarded 5-seed/100-neuron/1.2-s run showed stable normal
  Nengo decoding for LIF/T023/T033 and useful low-rate reset-gate/combined-state
  readouts for calibrated T023/T033. Treat the claim as a scalar represented
  signal result, not a closed-loop or high-dimensional decoder result.
- `build_paper.ps1` is idempotent. If `pdflatex` is not found it prints how to
  install MiKTeX.
