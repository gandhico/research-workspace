# Reproducibility

This document gives the exact steps to recreate the environment and regenerate
every artifact, plus notes on determinism and the toolchain used.

## 1. Environment

Verified configuration:

- Windows 11, PowerShell.
- Python **3.11.0**.
- `numpy 2.4.4`, `matplotlib 3.10.8`, `nengo 4.1.0`.
- LaTeX: **MiKTeX 25.12** (`MiKTeX-pdfTeX 4.23`), with on-the-fly package
  installation enabled.

### Create the Python environment

```powershell
scripts\setup_env.ps1
```

This creates `.venv`, upgrades `pip`, installs `requirements.txt`, and prints
the resolved versions. Equivalent manual steps:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install --upgrade pip
.venv\Scripts\python -m pip install -r requirements.txt
```

### Install the LaTeX toolchain

```powershell
winget install --id MiKTeX.MiKTeX -e --scope user
# enable silent package installation (build_paper.ps1 relies on it):
# (run once) initexmf --set-config-value "[MPM]AutoInstall=1"
```

`scripts\build_paper.ps1` searches for `pdflatex` on `PATH` and then in
`%LOCALAPPDATA%\Programs\MiKTeX\miktex\bin\x64`. TeX Live or Tectonic also work;
adjust `build_paper.ps1` if your `pdflatex` is elsewhere.

## 2. Regenerate everything

```powershell
scripts\build_all.ps1
```

Or, individually and in order:

```powershell
scripts\run_experiments.ps1   # results/csv/*.csv, results/logs/*.txt
scripts\make_figures.ps1      # results/figures + paper/figures (PNG + PDF)
scripts\make_tables.ps1       # paper/tables/*.tex
scripts\build_paper.ps1       # paper/main.pdf
```

Approximate run time on a typical laptop: experiments are usually seconds for
01--07 and 09, but `08_nef_app_smoke.py` uses canonical Nengo ensemble
calibration and can take several minutes; figures ~5 s, tables <1 s, first
LaTeX build longer if MiKTeX must download packages, then a few seconds.

## 3. Determinism

- The numerical results are **fully deterministic**: there is no random number
  generation in the single-neuron model, decoder, or metric scripts. The linear
  decoders use a fixed 70/30 split and `numpy.linalg.lstsq`. The NEF smoke uses
  fixed Nengo network seeds.
- The Nengo parity experiment injects current directly into a 1-neuron ensemble
  with fixed `gain=1`, `bias=0`, `encoders=1`, so no random tuning is involved;
  the agreement with the standalone model is exact by construction (shared
  numerical kernel — see `MATH_CODE_MAP.md` and the paper, Sec. "Nengo
  Implementation").
- Floating-point note: the `0` entries in `07_parity_metrics.csv` are exact
  zeros (identical IEEE-754 results), not rounded small numbers.

## 4. What to check after a rebuild

- `results/logs/03_current_sweep.txt` should report
  `HyperLIF DB-onset current (analytical): 2.4000` and
  `Fixed-HyperLIF latched voltage at I=4.0: predicted 1.3333, simulated 1.3333`.
- `results/logs/07_python_vs_nengo.txt` should show `voltage_rmse: 0.0`,
  `gate_rmse: 0.0`, `event_mismatch_count: 0` for both models and protocols.
- `results/logs/08_nef_app_smoke.txt` should show LIF and Adaptive as `ok`,
  base HyperLIF as `WEAK`, and nonzero oscillator amplitudes for all three.
- `results/logs/10_core_nengo_capability_sweep.txt` should show all
  communication/function/transform/memory/oscillator/PES app variants with
  `status=ok`, including θ_event and static-origin variants. These are
  approximate-calibration smoke metrics; the origin rows use `v_reset=-0.6` and
  `min_voltage=-2.0`.
- `results/logs/17_capability_seed_sweep_preflight_20260719.log` should end
  with `wrote ...17_capability_seed_sweep_summary.csv` and a summary showing
  84/84 completed simulations, `n=3`, and `fail=0` for every seven-app core
  capability row.
- `results/csv/13_hyperlif_nengo_capability_matrix.csv`,
  `results/csv/15_pes_rate_matched.csv`, and
  `paper/figures/fig_nengo_capability.png` should support the calibrated
  capability and PES trade figure/table claims.
- `experiments/14_backend_portability_probe.py` should remain the source for
  the backend rejection/status table.
- `experiments/18_nef_decoder_state_ablation.py --seeds 0,1,2,3,4
  --n-neurons 100 --duration 1.2` should write the final scalar NEF
  decoder-ablation CSVs and log used by `tab:nef-decoder-ablation`.
- The current `paper/main.pdf` build is 27 pages. The LaTeX log should have no
  undefined references/citations and no overfull boxes; `paper/main.blg` should
  report `warning$ -- 0`.

## 5. Cleaning

LaTeX intermediates (`*.aux`, `*.log`, `*.out`, `*.bbl`, `*.blg`) and the
`paper/_preview/` raster previews are disposable and listed in `.gitignore`.
`results/` and `paper/figures`, `paper/tables` are fully regenerated by the
runners.
