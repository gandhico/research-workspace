# Coupled cells on an external delayed-input task: gate basin transfer

**6 October 2026.** This is the independent-target follow-up to the
[one-connection teacher-recovery study](COUPLED_WEIGHT_HORIZON_AND_GATE_2026-10-06.md).
It uses no biological recordings or recognition dataset. The target is
prescribed from the external input, not generated by a teacher cell.
The result is a **negative control for broad performance claims** and a
specific demonstration that a good validation phase can miss a gate-basin
switch on a fresh phase.

## 1. Objective and exact gradient

For each fresh four-second phase, two recurrently coupled cells receive
the same rectified input splitter as earlier studies. The target is
`y(t)=u(t−20 ms)`, with zero target before 20 ms. Training phase is `0`,
validation `0.77`, and held-out test `1.91`; each starts from the declared
rest state. A linear readout uses either two voltages or two voltages plus
two internal states. The latter are raw readiness gates for HyperLIF and
adaptation states for the continuous two-state leaky control. The four
features have the same count but different physical meanings and current
scales; this remains a mechanism comparison, not a matched model ranking.

The directed connection `θ` is learned jointly with a **refitted ridge
readout**. For each fixed `θ`, training data determine

\[
(b^*,w^*)=\underset{b,w}{\arg\min}\;\frac1{2N}
\sum_k[b+w^\top x_\theta(t_k)-y_k]^2+
\frac{10^{-6}}2\|w\|^2.
\]

The episode objective derivative follows the envelope theorem while
the ridge optimum is smooth:

\[
\frac{dL^*}{d\theta}=
\frac1N\sum_k(\widehat y_k-y_k)
\,w^{*\top}\frac{\partial x_\theta(t_k)}{\partial\theta}.
\]

Exact forward sensitivity supplies the feature derivative; the local
version drops recurrent cross-cell tangent terms, as in the teacher
study. Eight fixed-`θ` episodes use a normalized eligibility step with
gains `0.25,0.5,1`. Gain selection uses validation only. The ridge
readout is refitted on the training phase after the last weight update
and then frozen for validation and the one test. Central finite
differences of the **refitted** objective at `θ=0` checked the exact
gradient; a `10⁻⁶` weight perturbation was needed for the nearly flat
high-gate case. The two-state leaky tangent was independently checked
against feature-level finite differences after correcting a numeric
literal ambiguity in the Julia code.

## 3. Mechanism of the `γ=2` failure

For the local voltage-selected `θ=0.565657`, the last-second mean gate
states on the training and validation phases are approximately
`(r1,r2)=(1,0)`. On test phase `1.91`, they become approximately
`(0,1)`. For local voltage+gate `θ=0.307155`, training/validation
again end near `(1,0)`, but test ends at `(1,1)`. At fixed `θ=0`, all
three listed phases end near `(1,0)`. The readout trained on one state
pattern therefore sees a different feature distribution after the
learned connection changes the trajectory basin. These are finite-time
observations, not a proof of global basin geometry. The exact late
means, final states, and separate event/occupancy counts are in
[`results/external_basin_audit_2026-10-06.csv`](results/external_basin_audit_2026-10-06.csv).

A streamed 17-by-33 grid over `θ∈[0,0.8]` and phase `φ∈[0,2π]`
classifies the **four-second final gate pattern** using `r>0.99` as
high and `r<0.01` as low. At `θ=0`, 21 of 33 sampled phases end
high/low and 12 end high/high. Near `θ=0.6`, 19 end high/low and
14 low/high. This maps sensitivity of the finite-time state to input
phase and coupling; it does not certify basin boundaries between grid
points. Data and code are
[`results/hyper_phase_basin_map_2026-10-06.csv`](results/hyper_phase_basin_map_2026-10-06.csv),
[`hyper_phase_basin_map.jl`](hyper_phase_basin_map.jl), and
[`plot_hyper_phase_basins.py`](plot_hyper_phase_basins.py).

![Finite-time HyperLIF gate-state map; open circles mark validation/test phases at the two selected local weights](results/hyper_phase_basin_map_2026-10-06.png)

The map connects the earlier ACC latch theorem to a learning failure:
once a gate is saturated, its local derivative is negligible; a
parameter update can nevertheless move the network into another
long-lived gate configuration under a fresh input. A locally correct
gradient on the training trajectory cannot guarantee transfer across
that discontinuous basin assignment. The event count remains zero in
all displayed cases, so event statistics alone would miss the change.

## 4. Scope and next control

This task uses a deterministic two-frequency input with only one train,
one validation, and one test phase. The phase grid was performed **after**
the original test failure as a diagnostic; it is not a new unbiased test.
The classical HH pair has not yet been trained on this external target.
The model currents and operating points remain different. Stronger
evidence needs several training/validation phases or independently
generated waveforms, a predeclared held-out collection, repeated initial
states, and fair optimization budgets. The immediate mathematical
question is whether a robust objective over a set of gate basins can
produce a connection whose readout remains useful across phases, or
whether `γ=2` should simply be excluded from this task regime.
