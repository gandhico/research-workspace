0. ONE-TIME POWERSHELL SETUP (do this first, every new terminal window)
============================================================
Two gotchas hit today, both because PowerShell state does NOT persist
between terminal windows/tabs — each new window starts clean:

(a) Running Launch_Gate_Residual_Demo.ps1 needs script execution allowed
    for that process. Run this ONCE per new terminal, before the launcher:

      Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

    Scope is "Process" — it only applies to the current window, not
    system-wide, and does not need Administrator. You'll need to run it
    again in any NEW terminal window/tab.

(b) If you see an error like "the expression after '&' ... produced an
    object that was not valid", it means a $PY variable from an earlier
    terminal window doesn't exist in this one. Either re-run the launcher
    (no $PY needed, see below), or use the fully-qualified fallback
    commands in section 3 — those never depend on a variable being set.
