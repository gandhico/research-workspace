# Audited ACC 2027 working draft

This package preserves the five-mission/two-model primary CMG-PES results,
separates the three traceable precursor annealing comparisons, and treats
selected Hover results as preliminary supporting tests.

## Overleaf

1. Upload the ZIP as a new project, or upload these files without deleting
   the existing v4 project files.
2. Select `ACC2027_v5_audited.tex` as the main document. Use pdfLaTeX and BibTeX.
3. The bibliography is `references_v5_audited.bib`. Keep both supplied PNGs
   under `figures/v5_audit/`.

The standalone package has all figure dependencies. No raw experiment
records or hardware software are changed by using this manuscript.

This is a working IEEEtran reading layout, not certified final ACC format.
Add verified human authors, affiliations, funding, and required disclosures;
apply the official ACC 2027 author kit and confirm the permitted page count
before submission.

Read `ACC2027_V4_TO_V5_AUDIT_2026-09-04.md` for corrections and unresolved
evidence. In particular, seven v4 annealing comparisons are withheld because
their matching saved outputs were not located; do not restore them solely
from the v4 table. Novelty is claimed for the CMG residual integration and
evaluation, not PES itself or the first Nengo/PES UAV implementation.
