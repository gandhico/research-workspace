# Technical audit: CMG, conventional neurons, and non-neural PES bases

## 1. Question under test

The experiment separates three claims that must not be conflated:

1. **PES residual learning works:** an online decoder can learn a bounded
   correction on top of a classical controller.
2. **A persistent continuous basis is useful:** PES needs an observable with
   sufficient occupancy and acceptable residual effort.
3. **CMG dynamics are specifically useful:** coupled membrane-gate dynamics
   outperform static non-neural features and appropriately operated standard
   neuron families.

The earlier family campaign established (1) but did not conclusively establish
(3). It used an older PD baseline, conventional LIF-like units were mostly
silent, Izhikevich was tonic, and the conventional-family PES normalization
contained one missing feature-scale factor. The present study corrects those
confounds against the final paper controller.

## 2. Common closed-loop interface

For desired quaternion `q_d`, measured quaternion `q`, and body rate `omega`,
the shortest-path quaternion error is

```
q_e = q_d (x) q^{-1},
e_q = sgn_+(q_e,0) q_e,v .
```

Every arm uses the same final baseline

```
u_0 = sat_l[-K_q (2 e_q) - K_omega (omega-omega_d)],
```

where the gains are generated by the disclosed `rho=3` bandwidth and
`omega_d` is the verified desired-rate feedforward. The three normalized
baseline coordinates are encoded as six signed currents:

```
n_j       = u_0,j / l_j,
I_j^+     = I_b + I_g max(n_j,0),
I_j^-     = I_b + I_g max(-n_j,0),
I         = [I_x^+, I_y^+, I_z^+, I_x^-, I_y^-, I_z^-]^T,
```

with `I_b=0.75` and `I_g=1.25` in the strict comparison. A basis produces
`a_k in [0,1]^6`. The decoder and teacher are common:

```
s_k       = clip_[−1,1](W_k a_k),
y_k*      = clip_[−1,1](−k_e e_q,k − k_omega omega_k),
epsilon_k = y_k* − s_k,
W_{k+1}   = Pi_[−6,6](W_k + eta epsilon_k a_k^T − lambda W_k),
W_0       = [I_3, −I_3].
```

The requested residual and final command are

```
delta_k = beta l (odot) s_k,
u_k     = sat_l(u_0,k + h_k (odot) delta_k).
```

The output-only saturation-opposition gate is axiswise:

```
h_j = 0, if |u_0,j| is at its limit and delta_j u_0,j < 0;
h_j = 1, otherwise.
```

It acts after decoding and before the outer torque clip. PES remains active.
Thus neuron-family conclusions are about the map `I -> a`; the baseline,
teacher, decoder, residual authority, actuator model, and gate are held fixed.

## 3. CMG basis

Each signed CMG unit has membrane state `v` and gate state `r`:

```
dot r = [sigma(alpha(v − (v_th − gamma r))) − r] / tau_r,
g(I)  = g_0 + chi g_1 |I|,
dot v = (v_rest + I − v)/tau + g(I) r^2 (v_reset − v),
a     = clip_[0,1](G r).
```

The paper-facing parameters are `tau=0.05 s`, `tau_r=0.005 s`,
`v_th=1`, `alpha=50`, `gamma=2`, `g_0=120`, `g_1=30`, and `G=10^5`.
The very large `G` means that a small positive gate is enough to saturate the
observable. Consequently, once the gate latches, `a` is often essentially
one. The intrinsic conductance term changes membrane dynamics, but prior
`chi=0/1` tests were numerically indistinguishable in the canonical regime.
The strong effect presently attributed to CMG is therefore **not proven to be
conductance adaptation**. It is the combination of a continuous persistent
observable, online PES, bounded authority, and output gating.

Two adaptations are distinct:

- `g(I)` is intrinsic current-dependent conductance inside the CMG unit.
- PES adapts the external decoder `W`. This is the dominant demonstrated
  learning mechanism.

## 4. Conventional Nengo bases

All spiking outputs are impulses of height `1/dt`, low-pass filtered with
`tau_f=5 ms`, then divided by a calibrated steady-state scale `S`:

```
a(t) = clip_[0,1]((h_tau_f * spike_train)(t) / S).
```

LIFRate uses the same filter and scale on its continuous rate output.

### LIF

Outside its refractory interval,

```
tau_rc dot v = J − v,
```

with threshold 1, reset 0, `tau_rc=20 ms`, and refractory time `2 ms`.
Under the strict map, an inactive signed branch receives `J=0.75<1`; an active
branch crosses threshold only when `|u_0,j|/l_j>0.2`. Therefore a strong final
baseline can keep many units silent. PES cannot update a decoder column when
its presynaptic activity is zero.

### Adaptive LIF (ALIF)

ALIF replaces `J` by `J−n` in the LIF equation and adds

```
tau_n dot n = inc_n z(t) − n,
```

where `z(t)` is the spike train, `tau_n=1 s`, and `inc_n=0.01`. It can be even
sparser than LIF because recent spiking raises the effective threshold.

### LIFRate

The continuous rate approximation is

```
a_raw(J) = 0,                                                J <= 1,
a_raw(J) = [tau_ref + tau_rc ln(1 + 1/(J−1))]^{-1},          J > 1.
```

It removes sampling variability but retains the same hard current threshold.
It is therefore a particularly clean test of whether the earlier result came
from spike sparsity or from the operating point itself.

### Izhikevich

Nengo's regular-spiking defaults implement, in millisecond-scaled form,

```
dot v = 1000(0.04v^2 + 5v + 140 − u + J),
dot u = 1000 a(bv − u),
```

with spike threshold `v>=30 mV` and reset `v<-65 mV`, `u<-u+8`,
`a=0.02`, `b=0.2`. The archived calibration multiplies canonical currents by
10. At `I_b=0.75`, this produces substantial tonic activity even when the
baseline torque is small. It gives PES persistent features, but can also cause
a nonzero residual floor and decoder rail occupancy on the extremely accurate
Roll and Yaw360 cases.

## 5. Exact PES normalization

This audit found a material issue in the archived conventional-family
comparison. Let native filtered activity be `p=S a`, and let the physical
Nengo connection be `Theta=W/S` so its decoded output is `Theta p = W a`.
Nengo `SimPES` applies

```
Delta Theta = eta_N dt/N (y*−s) p^T.
```

Therefore

```
Delta W = S Delta Theta
        = eta_N dt S^2/N (y*−s) a^T.
```

To reproduce the direct normalized update with rate `eta`, the correct Nengo
rate is

```
eta_N = eta N / (dt S^2).
```

The archived code used `eta N/(dt S)`, giving an effective normalized step
`S eta`: approximately 63x for LIF/LIFRate, 47x for ALIF, and 43x for
Izhikevich. The new runner verifies the corrected update numerically to machine
precision. Archived results remain useful as historical sensitivity evidence,
but they cannot support a strictly equal-learning-rate neuron comparison.

## 6. Non-neural mechanism controls

Two analytic bases retain the same `W`, PES, beta, torque limits, and output
gate, but contain no neuron:

1. **Constant-one:** `a_k=1_6`. This directly tests the persistent-basis
   reduction. The decoder is identifiable only through its row sums, and the
   effective output recursion is a leaky first-order tracker of `y*`.
2. **Static paired-current:**

   ```
   a_k = clip_[0,1](I_k/(I_b+I_g)).
   ```

   This retains the signed input dependence but removes all membrane, gate,
   spike, reset, adaptation, recovery, and synaptic state except the PES
   decoder itself.

Interpretation is deliberately asymmetric: matching CMG would show that a
neuron is unnecessary **in this tested regime**; failing to match CMG would
support, but not by itself prove, a useful role for CMG temporal dynamics.

## 7. Family-specific optimization without moving the goalposts

Neuron-specific optimization is scientifically legitimate because equal raw
current does not imply equal excitability. The admissible tuning variables are

- current bias and gain (with `I_b+I_g=2` so the archived maximum-response
  scale remains valid), and
- output filter time constant (`5` or `20 ms`).

The following are **not** retuned per neuron or per mission: beta, teacher,
direct-equivalent eta, decoder bounds/leak, controller gains, actuator limits,
mission, and performance metric. Settings are selected on X2 Roll + Hard45 to
span a very-low-error and moderate-error regime, then frozen for X2 held-out
missions and all CF2 missions. This prevents a per-mission oracle.

## 8. What can be concluded

The final conclusion must follow this hierarchy:

- If exact-normalized LIF/ALIF/LIFRate remain silent and threshold-aware tuning
  makes them useful, the old negative result was not intrinsic.
- If exact-normalized Izhikevich loses its residual floor while retaining
  learning, the old degradation was partly the PES scaling error.
- If Izhikevich remains high-effort after exact normalization, tonic activity
  is independently implicated.
- If one or both no-neuron bases match CMG, the paper should emphasize online
  bounded PES residual learning with a persistent continuous basis, with CMG
  as a neuromorphic realization—not claim a unique CMG learning property.
- Only if CMG consistently dominates both analytic bases and tuned standard
  families at comparable effort should the result be framed as evidence for
  an intrinsic CMG advantage.

## 9. Controller expansion after this decision

Existing PD, PID, LQR, backstepping, SMC, MPC, and NMPC implementations are
not equivalent experimental baselines. The prior audit already shows that CMG
helps the model-free PD+feedforward baseline but generally does not improve
well-specified LQR/backstepping/unconstrained MPC, while SMC is sensitive to
its boundary layer and the current NMPC is a low-rate grid approximation.

The next study should hold the selected basis fixed and add the residual at a
well-defined location:

| Controller | Residual location | Required anti-windup/consistency check |
|---|---|---|
| PD / PID | additive body torque after baseline | PID integrator must use rotor-level saturation feedback |
| LQR | additive body torque after state feedback | compare against the same reference-rate convention |
| Backstepping | additive matched uncertainty after computed torque | test inertia/model mismatch; exact-model nominal may leave nothing useful to learn |
| SMC | inside or outside boundary-layer equivalent torque, declared explicitly | verify no chattering reintroduction and compare matched disturbance rejection |
| MPC | preferably learned disturbance in prediction model; output residual only as a secondary ablation | enforce real input constraints, not post-hoc clipping only |
| NMPC | learned model/disturbance term at optimizer update rate, with a clearly defined high-rate hold/residual path | separate optimizer, hold, and 2 kHz neural clocks |

This expansion should begin only after the present basis experiment determines
what component is transferable. Otherwise controller and neuron effects remain
confounded.
