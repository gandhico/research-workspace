# Partial archived-scaling run — do not use as the confirmatory matrix

This directory contains the first nine cases of an interrupted campaign. The
campaign was stopped when an audit showed that the archived conventional-family
adapter implemented an effective normalized PES step `S*eta`, rather than the
CMG/direct step `eta`. The files are preserved for transparency, but are not a
complete matrix and must not be combined with `strict_exact`.

The corrected confirmatory matrix is in `../strict_exact/`.
