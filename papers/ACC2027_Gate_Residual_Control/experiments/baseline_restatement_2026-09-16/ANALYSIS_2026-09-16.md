# Baseline restatement: tables and figures for review before any paper edit

2026-09-16. Assembled from existing runs only — no new simulation, nothing canonical touched.
Builder: `build_restatement.py` (read-only over the two result folders listed below).

The question this answers: **what exactly is the CMG–PES residual being compared against, and what
survives when the baseline is repaired?**

## 1. What is in each column

All errors are **mean quaternion-angle error in radians** over a 45 s mission, dt = 0.5 ms, one
deterministic run per cell, noise-free unless a row says otherwise. Lower is better.

| column | controller | where it comes from |
|---|---|---|
| **PD (Table V)** | the paper's baseline: `−k_q e_q − k_ω ω`, saturated, no integral, no feedforward, ω_n = (4, 4, 3.5) | published Table V |
| **CMG \| PD** | the paper's result: bounded CMG–PES residual on that PD | published Table V |
| **PD+ff (1×)** | same gains, but damping the *rate error* `ω − ω_d` that the paper's own eq. (6) defines | `rate_ff_summary.csv` |
| **CMG \| PD+ff (1×)** | residual on the feedforward PD, same β, η, k_e as Table V | `rate_ff_summary.csv` |
| **PD+ff (tuned 3×)** | feedforward PD with its bandwidth at the swept optimum, ω_n × 3 | `cmg_beta_summary.csv` |
| **CMG \| PD+ff (3×)** | residual on that, at the β chosen by the rule fixed in code (X2 0.5, CF2 0.05) | `cmg_beta_summary.csv` |

Sources: `experiments/nengo_nef_replication_2026-08-29/results/pid_baseline_2026-09-10/` and
`.../results/baselines_2026-09-10/`. Full numeric output: `master_table.csv`, `bandwidth_sweep.csv`,
`TABLES.md` (T1–T4).

## 2. The ladder — Figure 1, Tables T1 and T2

![ladder](fig1_baseline_ladder.png)

Geometric mean over the five missions:

| | X2 | CF2 | vs PD |
|---|---|---|---|
| PD (Table V) | 0.17312 | 0.16868 | — |
| CMG \| PD (the paper's result) | 0.09602 | 0.09411 | −44 % / −44 % |
| PD+ff, Table V bandwidth | 0.02619 | 0.02039 | −85 % / −88 % |
| CMG \| PD+ff (1×) | 0.01104 | 0.00865 | −94 % / −95 % |
| PD+ff, tuned 3× | 0.00454 | 0.00377 | −97.4 % / −97.8 % |
| CMG \| PD+ff (3×) | 0.00293 | 0.00352 | −98.3 % / −97.9 % |

**Reading.**

1. **The headline is real but small on this ladder.** CMG on PD removes 17.3–60.6 % of PD's error
   (T2, column 5) — exactly the paper's claim. Adding the missing feedforward *alone* removes
   76–99 % on the four moving-reference missions, and the tuned bandwidth removes 96–99.9 %.
2. **The contested cell is column 8 of T2, `tuned PD+ff / CMG|PD`.** It is below 1 in all ten cells:
   0.003–0.077 on the moving-reference missions and 0.74–0.76 on Hardstep. A plain, tuned, non-learning
   PD with feedforward beats the paper's CMG result everywhere, by 13–300× on smooth missions.
3. **Hardstep is the exception that explains the rest.** Feedforward does nothing there (−0.1 % / +0.1 %),
   because the reference is piecewise constant — there is no reference rate to feed forward. What helps
   Hardstep is bandwidth (41.5 % / 38.4 %), and that is limited by rotor saturation.

## 3. Where the bandwidth optimum is — Figure 2, Table T4

![bandwidth](fig2_bandwidth_sweep.png)

| platform | noise | 0.75× | 1× | 1.5× | 2× | **3×** | 4× | 6× | 8× |
|---|---|---|---|---|---|---|---|---|---|
| X2 | none | 0.16465 | 0.12053 | 0.08136 | 0.06673 | **0.05742** | 0.05959 | 0.07060 | 0.08249 |
| X2 | realistic | 0.17853 | 0.13655 | 0.10106 | 0.08938 | **0.08322** | 0.08633 | 0.09780 | 0.51929 |
| CF2 | none | 0.14309 | 0.10550 | 0.07419 | 0.06266 | **0.05579** | 0.43219 | 0.50450 | 0.50931 |
| CF2 | realistic | 0.15761 | 0.12307 | 0.09639 | 0.08761 | **0.08293** | 0.46676 | 0.53366 | 0.53657 |

(arithmetic mission-mean error, the quantity the selection rule minimised; the geometric mean is in T4.)

**Reading.**

1. **The optimum is interior at 3× in all four combinations** — both airframes, noise-free and under the
   paper's own noise model. So the Table V gains sit a factor of 3 below the best setting of the same
   control law, and that is not an artifact of tuning without noise.
2. **What stops it going higher is the actuator, not the structure.** X2 Hardstep rotor-bound occupancy
   climbs 0.000 → 0.086 from 1× to 3×; CF2 diverges from 4× upward (Hardstep 0.26 → 2.15 rad, rotors at a
   bound 83 % of the time). Hardstep caps the gain for every controller family we tested.
3. **Honest nuance for the paper.** If you score by *geometric* mean instead — which de-emphasises
   Hardstep — the noise-free error keeps falling past 3× (X2 0.00454 at 3× → 0.00142 at 8×). "Interior
   optimum at 3×" is therefore a statement about the Hardstep-inclusive arithmetic mean and about the
   noisy case, not about smooth-mission tracking in isolation. Say which mean is used.
4. **The flat floor in the bottom row is the measurement-noise floor** (0.032 rad), not control
   performance: under noise, `qerr` is computed from the noisy measurement. This is the same issue
   flagged for Table VI of the paper.

## 4. What the residual still buys — Figure 3

![cmg gain](fig3_cmg_gain_vs_baseline.png)

Error reduction by CMG–PES against **its own** baseline, per mission:

| baseline it sits on | X2 | CF2 |
|---|---|---|
| PD (the paper's pairing) | +17 % to +61 % | +17 % to +61 % |
| PD+ff at Table V bandwidth | +21 % to +80 % | +18 % to +80 % |
| PD+ff, tuned 3× | +12 % to +78 %, Hardstep **−17 %** | +1.3 % to +23 %, Hardstep −1.3 % |

**Reading.**

1. **On the 1× feedforward baseline the residual is not weakened — it is slightly stronger** (geo-mean
   0.01104 vs 0.02619, a 58 % reduction, versus 44 % on plain PD), and it does it with a **4–40× smaller
   mean residual torque** (T3) and no added saturation. This is the strongest single argument available:
   the residual is not merely re-inventing the feedforward term.
2. **On the tuned 3× baseline the picture splits by airframe.** X2 still gains substantially
   (geo-ratio 0.64), CF2 only marginally (0.94) and only at β = 0.05, because β ≥ 0.1 drives CF2 Hardstep
   into divergence. On both, Hardstep goes the wrong way.
3. **The pattern is consistent with everything else we measured:** the residual helps where the baseline
   lacks a model term, and has little to add once the baseline is near its own ceiling.

## 5. Effort and safety — Table T3

Worth carrying into the paper because it is favourable and currently unreported:

- Mean residual torque, X2 Full3: 0.121 N·m on PD → 0.0216 N·m on PD+ff (1×) → 0.0148 N·m on the tuned
  baseline. The better the baseline, the less authority the residual actually exercises.
- Saturation stays at 0 on every moving-reference cell; the only non-trivial occupancy is X2 Hardstep on
  the tuned baseline (0.035), which is the bandwidth's doing, not the residual's.
- CF2 residual torques are ~10⁻⁵ N·m, i.e. four orders below X2 — the airframes are not comparable in
  absolute effort, only in relative error.

## 5b. Hardstep, resolved (added 2026-09-16)

Full write-up: `HARDSTEP_FINDINGS_2026-09-16.md`. Summary:

- Hardstep commands 63–111° rotations every 2 s; **97–99% of its 45-s mean error is slew** that no
  bounded residual can remove. Settled error is already 3.4° (X2) and 0.7° (CF2).
- The binding axis is X2 yaw, whose controller torque box (0.254 N·m) is **97% of the rotor-feasible
  torque at hover** (0.261 N·m). PD runs at 1.2–2.2× the per-step time-optimal bound; CMG lands on it.
- Scored by **settling time to a 5° band**, the residual gives **−31% (X2)** and **−42% (CF2)** at the
  canonical bandwidth — against the 21%/18% the mean-error metric reported. It costs settled accuracy
  (CF2 0.67° → 1.38°).
- At ρ=3 the loop bandwidth (12 rad/s) passes the **9.6 rad/s PES corner**, the lagged residual falls
  out of phase, and it slows the step instead (X2 0.59 → 0.83 s).
- A pre-registered fix hypothesis (torque limits from diag(J)) was **refuted** by experiment: it puts
  the yaw box 2.3× above rotor capability and takes X2 ρ=3 from 15.3° to 89.8° with 68% saturation.
- X2 descends to 0.117 m during Hardstep with 7.5 cm of rotor clearance — no contact, but worth
  disclosing.

**Consequence for the tables:** Tables II, III and IV merge into one two-column matrix
(`tex_table_all.tex`, generated by `make_merged_table.py`) whose last block reports the Hardstep step
response. Measured cost: 561 pt of single-column area against 437 pt for the three separate tables,
i.e. the merge buys organisation and ~60 new numbers, **not** space.

## 7. Caveats that must travel with these numbers

1. **One deterministic run per cell.** The paper's noise table shows seed spread of 0.002–0.031 %, so
   this is adequate for noise-free cells, but no error bars are implied.
2. **Bandwidth and β were tuned on the evaluation missions.** That favours the *baseline* in every
   comparison here, which is the conservative direction for a CMG claim, but it should be stated.
3. **β on the tuned baseline was selected by a rule fixed in code before the results existed**
   (X2 0.5, CF2 0.05). CF2 admits only a small authority because β ≥ 0.1 diverges on Hardstep.
4. **Table V CMG cells reproduce to ≤ 2.1×10⁻⁶ relative, not bit-exactly** (two CMG modules were edited
   after those runs; no printed value changes). PD cells reproduce bit-for-bit. The CMG\|PD column here
   is today's rerun, so it differs from CMG\|PD+ff only by the baseline.
5. **Under noise the reported error contains the sensor noise** (floor 0.032 rad). Any noisy comparison
   below that floor is not resolving control performance.
