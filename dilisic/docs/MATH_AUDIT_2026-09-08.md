# DILISIC mathematical and implementation audit

## Status

The local code is a stable engineering replication of the paper's seven-agent
experiment, not yet a theorem-level reproduction. The plant, LISIC structure,
Riccati term, RBF count, disturbance, and reference are represented. The exact
Appendix obstacle/flocking geometry and the paper's undisclosed adaptation and
projection bounds are not recoverable from the article alone.

## Reconstructed contract

For the scalar relative-degree-(n) plant

\[
x^{(n)}=f(\mathbf x)+g(\mathbf x)u+d,\quad g(\mathbf x)>0,
\]

use (e=x-x_d) and

\[
s=e^{(n-1)}+\lambda_{n-1}e^{(n-2)}+\cdots+\lambda_1e,
\]

where the polynomial (z^{n-1}+\lambda_{n-1}z^{n-2}+\cdots+\lambda_1)
is Hurwitz. Then

\[
\dot s=f+gu+q_a+d,\qquad
q_a=-x_d^{(n)}+\lambda_{n-1}e^{(n-1)}+\cdots+\lambda_1\dot e.
\]

The implemented law

\[
u=-\hat h(\hat f+q_a+Ks-u_r),\qquad \hat h\approx 1/g,
\]

matches Eqs. (3), (4), and (14) with this convention. The robust state is
(s_e=[s,\xi]^T, \dot\xi=s), and

\[
u_r=-B_e^TP_es_e/r,
\]

where (P_e\succ0) solves the stated CARE with
(R=\rho^2r/(2\rho^2-r)) and therefore requires (2\rho^2>r).

In DILISIC, (x_d) is generated by (\ddot x_d=u_{DI}), and the plant input
is (u_{DI}+u_{LISIC}). A code defect used a filtered (u_{DI}) in the
reference and the raw (u_{DI}) at the plant. This is now corrected: both
receive the same filtered signal; the raw outer command remains logged.

## Paper-level issues that must be stated explicitly

1. **Tracking-error sign conflict.** Section III uses (e=x-x_d); Section V
   Eq. (30) prints (e=x_d-x). These cannot both be used without changing the
   signs in (s,q_a), and the control. The code adopts Section III because it
   is internally consistent with Eqs. (3), (4), and (14).
2. **Potential Lyapunov-proof gap.** Eq. (20) divides the (\tilde V_h) and
   (\tilde W_h) energy terms by the state-dependent optimal approximator
   (\hat h^*(\mathbf x)). Eq. (21) differentiates those terms as if
   (\hat h^*) were constant, omitting terms proportional to
   (d(1/\hat h^*)/dt). The proof is complete only if (\hat h^*) is treated
   as a positive constant, or if omitted derivative terms are bounded and
   absorbed. The article does not state that extra condition.
3. **Positivity is not established for the approximator.** (g>0) implies
   (h=1/g>0), but finite RBF approximation error does not alone guarantee
   (\hat h^*>0). Eq. (20) needs a positive lower bound. The code enforces an
   `h_hat_floor`; that is defensible engineering but not a paper equation.
4. **Projection typography.** Eq. (25)'s (W_f) projection term appears with
   a (\|W_h\|) denominator; the projection geometry requires
   (\|W_f\|). The implementation uses the mathematically standard radial
   projection for each weight vector independently.
5. **Dimension mismatch in exposition.** The Appendix introduces agents in
   (m=2,3), while the numerical flexible-arm mission is scalar/1-D. A 1-D
   specialization is reasonable, but obstacle beta-agent geometry from the
   cited flocking papers must be specified; it cannot be reconstructed from
   Eqs. (39)-(43) alone.
6. **Complexity notation is overloaded.** The article uses (n) for system
   order and discusses controller complexity (O(n)) in an agent-count
   context. Report complexity in terms of agents (N), neighbors (|E|), and
   basis count (p): a local update is (O(p+\deg i)), and a sparse network
   step is (O(Np+|E|)).

## Implementation corrections in this audit

- Fixed the raw/filtered (u_{DI}) contract.
- Fixed an off-by-one integration error: a requested duration (T) previously
  advanced the plant to (T+\Delta t), and logged post-step state at pre-step
  timestamps.
- Added explicit tests for the sign convention, inverse-gain initialization,
  duration semantics, and common reference/plant input.
- Added center-of-mass/reference/error plots with obstacle and disturbance
  intervals.

## QArm boundary for tomorrow

The current controller cannot be safely connected directly to a QArm. It needs
four derivatives for each scalar output, assumes an affine command entering the
highest derivative, and returns an input in the flexible-arm model's units. The
installed QArm API presents a position-servo interface; QArm Mini additionally
offers PWM. Before actuation, identify each selected joint's command-to-position
model, validate the relative degree and sign of the input gain, estimate missing
derivatives with a bandwidth justified against encoder noise, and execute the
controller in shadow. Without these steps, “works perfectly” would be an unsafe
and scientifically unsupported claim.
