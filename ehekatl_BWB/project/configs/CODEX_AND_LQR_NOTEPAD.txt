LQR PITCH-ONLY DIAGNOSTIC
-------------------------

Trim X-Plane close to pitch=2 deg, roll=0 deg before running.

python lqr/run_lqr_xp12.py \
  --duration 4 \
  --hz 20 \
  --controller lqr \
  --mode attitude \
  --axis pitch \
  --rate-units deg_s \
  --routing legacy \
  --trim-source current \
  --trim-mode incremental \
  --pitch-sp 2 \
  --roll-sp 0 \
  --clip 0.08 \
  --throttle -998 \
  --max-abs-pitch 25 \
  --max-abs-roll 35 \
  --max-abs-rate 80 \
  --out logs/lqr_pitch_lqr_$(date +%Y%m%d_%H%M%S).csv

If pitch moves away from 2 deg, rerun with:
  --elevator-sign -1

WHAT TO REPORT BACK TO CODEX
----------------------------

After each LQR run, report:
  1. The exact CSV path printed by the runner.
  2. The CTRL trim bias line printed at startup.
  3. Whether pitch moved toward 2 degrees or away from it.
  4. Whether roll moved toward 0 degrees or away from it.
  5. Whether stop_reason was empty or a safety limit triggered.

Current LQR integration defaults:
  --rate-units deg_s
  --routing legacy
  --trim-source current
  --trim-mode incremental
  --elevator-sign 1
  --aileron-sign -1
